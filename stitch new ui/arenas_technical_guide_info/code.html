Zero Cash Value Notice

Arenas operates on a strictly play-money basis using synthetic campus tokens. Markets hold zero real-world cash value and are designed purely for educational and predictive modeling purposes. No fiat currency can be deposited or withdrawn.

LMSR Mathematical Model

Arenas utilizes a Logarithmic Market Scoring Rule (LMSR) Automated Market Maker (AMM) to ensure continuous liquidity and bound maximum loss for market creators.

functions Cost Function C(q)

The total cost of outstanding shares is calculated using the standard LMSR cost function.

C(q) = b * ln( Σ e^(q_i / b) )
percent Implied Probability

The instantaneous marginal price (or implied probability) of a specific outcome i.

p(i) = e^(q_i / b) / Σ e^(q_j / b)
tune

The Liquidity Parameter (b)

The parameter b dictates market depth. A larger b requires more volume to shift prices, simulating deep liquidity, but increases the maximum possible loss (subsidy) for the market creator, bound at b * ln(N) where N is the number of outcomes.
